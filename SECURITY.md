# Security Policy

## Reporting a vulnerability

Please use GitHub's private security-advisory mechanism for the affected AgentProof repository. Do not
place credentials, sensitive trace content, exploit payloads, or production evidence in a public issue.

## Scope

This repository governs documentation and docs-as-code validation. A component vulnerability belongs
to the component repository whose executable contract is affected. Cross-repository boundary concerns
should reference this platform repository and the affected component without reproducing sensitive
payloads.

## Maintainer response

Maintainers will acknowledge the report, determine the affected evidence boundary, coordinate the
least-disclosure remediation, add a deterministic regression where applicable, and publish release
notes after a reviewed fix and hosted verification complete.
